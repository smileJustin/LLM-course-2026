> 课件要求：
> - 用 Gensim 做文本向量化表示学习实验；训练 FastText，基于向量完成文本分类实验，并阅读源码、对照论文。
> - 表示学习使用自选的干净中英文语料；分类使用人民日报 9801，自选标签，分类数量由少到多。
> - 基础：跑通全流程；进阶：读懂论文、对比 Gensim 实现；高级：理解周边代码及参数、超参数的设置与意义。

- Python 3.10，依赖 `gensim`、`fasttext-wheel`、`numpy<2`（fastText 0.9.x 与 numpy 2 不兼容）。
- 语料放在仓库根目录 `1998-上半年-带音(1)/1998-上半年-带音/`，或者运行时用 `--data` 指定。

## 实验一：Gensim word2vec（`word2vec_gensim.py`）

### 设置
- 语料：1998 年 1~6 月全部段落，每段作为一个“句子”。
- 两个模型除 `sg` 外参数完全相同，便于对比：

| 参数 | 取值 | 含义（对照论文） |
|---|---|---|
| `sg` | 1 / 0 | Skip-gram（中心词预测上下文）/ CBOW（上下文平均预测中心词） |
| `vector_size` | 100 | 词向量维度 |
| `window` | 5 | 最大窗口。Gensim 实际对每个词在 1~5 之间随机取窗口，近的词被采到的机会更多 |
| `min_count` | 5 | 出现少于 5 次的词丢弃 |
| `negative` / `hs` | 5 / 0 | 负采样，每个正例配 5 个负例，负例按 词频^0.75 抽样（Mikolov 2013b 第 2.2 节） |
| `sample` | 1e-4 | 高频词下采样，“的、了”等会被随机丢弃（第 2.3 节） |
| `epochs` | 5 | 遍历语料 5 轮，学习率从 0.025 线性衰减 |

### 评估方式
1. **最近邻**：看“经济、银行、足球”等词附近的词是否语义相关；
2. **词类比**：a : b = c : ?，用 b − a + c 的最近词作为答案，例如 中国:北京 = 日本:?（期望“东京”）；
3. **词对相似度**：相关词对（足球-篮球）的相似度是否高于无关词对（足球-银行）；
4. **找不同**：在“足球、篮球、排球、银行”中能否挑出“银行”。

### 结果（6 个月语料，620 万词，词表 43,332）
| | Skip-gram | CBOW |
|---|---|---|
| 训练用时（5 轮） | 28.7 s | **8.7 s** |
| 词类比第 1 名命中 | **3/5** | 1/5 |
| 足球 - 篮球 / 足球 - 银行 相似度 | 0.77 / 0.31 | 0.88 / **0.09** |
| 找不同（2 组） | 2/2 | 2/2 |

近邻示例（Skip-gram）：经济 → 发展、国民经济；银行 → 分行、信贷、贷款；足球 → 排球、篮球、联赛；春节 → 元旦、除夕。
Skip-gram 在类比上更好（中国:北京 = 日本/法国/俄罗斯 : 东京/巴黎/莫斯科 全对），CBOW 快 3.3 倍，近邻更偏“同类可替换”的词。详见 `实验报告.md`。

## 实验二：fastText 文本分类（`fasttext_classify.py`）

### 标签怎么选（自选标签）
行编号 `19980101-06-003-002` 依次是 日期-版面-文章号-段落号。人民日报各版面相对固定：01 要闻、06 国际、08 体育……所以把**版面号当作文章类别**，不需要人工标注。同一 日期-版面-文章号 的段落合成一篇文章，9801 共 3132 篇，每篇取前 200 个词（标题和导语已经包含主要信息）。每组实验都固定随机种子，按 80% / 20% 划分训练集和测试集。

### 模型与参数（对照 Joulin et al. 2017）
```
文章 → 词 + 相邻词二元组(bigram) → 哈希到桶 → 查表得 100 维向量 → 取平均 → 线性层 → softmax
```
| 参数 | 取值 | 含义 |
|---|---|---|
| `wordNgrams` | 2 | 加入 bigram 特征，弥补词袋丢失的局部词序（论文第 2.2 节） |
| `dim` | 100 | 词向量维度，和实验一的词向量一致，才能用 `pretrainedVectors` |
| `epoch` / `lr` | 25 / 1.0 | 数据只有几千篇，需要更多轮数和更大学习率，与 fastText 官方教程的建议一致 |
| `loss` | softmax | 最多 12 类，普通 softmax 就够；类别上万时才需要层次 softmax（论文第 2.1 节） |
| `minCount` | 1 | 保留所有词 |
| `thread` / `seed` | 1 / 1 | 单线程、固定种子，结果可复现 |

### 实验设计
| 实验 | 目的 |
|---|---|
| 2 类：06 国际 vs 08 体育 | 内容差别最明显的两个版面 |
| 4 类：01 / 06 / 08 / 12 | 增加类别数 |
| 12 类：全部版面 | 类别最多，也包括内容不固定的版面 |
| 对照 1：12 类，`wordNgrams=1` | 看 bigram 特征的作用 |
| 对照 2：12 类，`pretrainedVectors` | 用实验一在 6 个月语料上训练的 Skip-gram 向量初始化，看“预训练向量”对小数据分类有没有帮助 |

### 结果
| 实验 | 测试准确率 | 基线（全猜最多的类） |
|---|---|---|
| 2 类：06 国际 vs 08 体育 | **94.6%** | 66.3% |
| 4 类：01 / 06 / 08 / 12 | **87.3%** | 35.4% |
| 12 类：全部版面 | **47.4%** | 11.5% |
| 对照 1：12 类，只用单词 | 47.2% | 11.5% |
| 对照 2：12 类，word2vec 向量初始化 | **51.5%** | 11.5% |

- 类别越多准确率越低，主要因为部分版面（09、11、12）在不同日期刊登不同专刊，版面号与主题不一一对应。
- bigram 对主题分类几乎没有帮助（+0.2），却让训练时间变成 3 倍。
- 预训练词向量带来 +4.1 个百分点；但词向量语料包含 1 月份，这个提升偏乐观。

完整分析见 `实验报告.md`。
