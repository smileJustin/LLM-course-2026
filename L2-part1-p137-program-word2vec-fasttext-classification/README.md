## 一、表示学习：word2vec（Skip-gram + 负采样）

### 算法与参数对照
| 步骤 | 代码 | 论文 / Gensim 参数 |
|---|---|---|
| 建词表，去掉低频词 | `min_count=5` | `min_count=5` |
| 高频词下采样（“的、了”等被随机丢弃） | `keep_prob` | 论文 2.3 节；`sample=1e-4` |
| 动态窗口：在 1~window 之间随机取 | `randint(1, window)` | `window=5` |
| 中心词预测上下文词 | `_update(center, context)` | `sg=1` |
| 每个正例配 5 个负例，按 词频^0.75 抽样 | `neg_table` | 论文 2.2 节；`negative=5, ns_exponent=0.75` |
| 损失 log σ(u·v) + Σ log σ(−u'·v) | `_update` | 论文公式 (4) |
| 学习率从 0.025 线性衰减 | `train` | `alpha=0.025` |
| 输入向量随机初始化，输出向量初始化为 0 | `__init__` | 与 C 源码 / Gensim 相同 |

### 结果（30 万词，50 维，3 轮）
去掉公共方向后的最近邻：

| 词 | 最近邻 |
|---|---|
| 经济 | 结构、发展、产业、基础、水平、机制、稳定、提高 |
| 增长 | 低、速度、收入、保持、生产、水平、市场、调控 |
| 银行 | 美元、卢布、预计、合并、当局、汇率、东南亚 |
| 北京 | 记者、电、1月、5日、新华社、本报、8日 |
| 足球 / 电脑 / 学生 | 几乎没有规律 |

### 观察
1. **高频词效果好，低频词效果差**。“经济、增长、银行”在 30 万词里出现上百次，近邻合理。“足球、电脑”只出现几次，向量基本是噪声。表示学习需要足够的共现次数，Gensim 也一样。
2. **“北京”的近邻是“新华社、记者、5日、电”**：人民日报里“北京”最常出现在电头“新华社北京 1 月 5 日电”中。词向量学到的是**分布**（在什么语境出现），不是概念本身。在这个语料里，“北京”和“记者”的语境确实最相似。
3. **所有原始相似度都接近 1**。直接用原始向量算余弦相似度时，任意两个词都在 0.99 以上（见运行结果）。原因是小语料、训练轮数少时，词向量 99% 以上的方差集中在一个公共方向上，这个方向主要编码词频。去掉平均向量和第一主成分以后（All-but-the-Top，Mu & Viswanath 2018），语义差别才显现。Gensim 在小语料上训练，同样会出现“所有相似度都是 0.99”的现象。
4. **纯 Python 速度**：约 9 万个正例对每秒，比 C 实现的 Gensim 慢两三个数量级，所以这里只用了 30 万词。可以用 `--max-tokens 1000000` 加大语料，但用时会成比例增加。

## 二、FastText 文本分类

### 标签怎么选（自选标签）
人民日报语料每行的编号 `19980101-06-003-002` 依次是 **日期-版面-文章号-段落号**。版面相对固定：01 要闻、06 国际、08 体育……所以把**版面号当作文章类别**，不需要人工标注。同一 日期-版面-文章号 的段落合成一篇文章，共 3132 篇，每篇取前 200 个词（标题 + 导语）。

### 模型（对照 Joulin et al. 2017）
```
文章 → 词 + 相邻词二元组(bigram) → 哈希到 2^18 个桶 → 查表得 10 维向量 → 取平均 → 线性层 → softmax
```
| 论文要点 | 代码 |
|---|---|
| 文本表示 = 词向量平均（无隐藏层，所以快） | `_forward` |
| 加 n-gram 特征弥补词袋丢失的词序 | `features`，`word_ngrams=2` |
| 哈希技巧：bigram 不建词表，直接映射到固定的桶 | `zlib.crc32(...) % buckets` |
| 类别很多时用层次 softmax 加速 | 本作业最多 12 类，普通 softmax 就够，没有实现 |
| SGD，学习率线性衰减 | `train` |

### 结果（80% 训练 / 20% 测试，25 轮，lr 1.0）
| 分类任务 | 测试准确率 | 基线（全猜最多的类） |
|---|---|---|
| 2 类：06 国际 vs 08 体育 | **95.7%** | 66.3% |
| 4 类：01 / 06 / 08 / 12 | **88.4%** | 35.4% |
| 12 类：全部版面 | **47.4%** | 11.5% |
| 12 类，只用单词（去掉 bigram） | 45.8% | 11.5% |

### 观察
1. **类别越多，准确率越低，主要原因在标签而不是模型**。国际、体育两版内容稳定，12 类里召回率仍有 74%、76%。第 01、02 版都是要闻类，彼此大量混淆。第 9、11、12 版之间混淆最多：这些版面在不同日期刊登不同的专刊（如消费、信息、周刊），版面号和内容主题不是一一对应的。12 类 47% 的准确率，反映的是“版面”这个标签定义的模糊程度。这呼应了 L1 讲过的：**任务定义决定分数在评价什么**。
2. **bigram 有帮助但不多**（+1.6 个百分点）。在主题分类上，单个词已经携带大部分信息。
3. **第一次用默认的 5 轮、lr 0.5 时严重欠拟合**，2 分类只有 66%，和瞎猜一样。数据只有几百篇时，需要更多轮数和更大学习率，fastText 官方教程也建议这样做。参数和数据规模要匹配。
4. **速度**：模型只是“查表 + 求平均 + 一个线性层”，所以即使用纯 Python，2500 篇文章训练 25 轮也只要 1 分钟左右。这正是 fastText “又快又够用”的原因。
