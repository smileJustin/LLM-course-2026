# L1 第125页 编程作业：n-gram 语言模型训练与续写

## 作业要求（课件原文要点）
1. 用人民日报切分标注语料，清理多余的 tag 和标签（为什么要清理？），训练 n-gram 模型。
2. 对比训练时间，观察训练过程；用不同参数生成文本，以“在阳光明媚的五月，我们学校胜利召开了……”开头续写。
3. 分享训练过程和成果。

## 怎么运行
- **PyCharm**：打开 `ngram.py`，右键 → Run。脚本默认读取上一级文件夹里的 `1998-上半年-带音(1)/1998-上半年-带音/*.txt`。
- **改参数**：Run → Edit Configurations → Parameters，例如：
  - `--months 1 --max-n 4`：只用 1 月语料，训练到 4-gram
  - `--temperature 1.2 --top-k 20`：只用这一组参数续写
  - `--data D:\某个路径`：语料放在别处时指定路径
- 全量 3-gram 大约需要 1 分钟、1.5GB 内存。电脑内存小的话先用 `--months 1`。

## 1. 语料清理：清理了什么，为什么要清理
原始一行长这样：
```
19980101-01-001-008 在 这{zhe4} 一 年 中 ， 中国 的 改革 开放 ……  １９９７年 ……
```
| 清理项 | 做法 | 为什么 |
|---|---|---|
| 行首编号 `19980101-01-001-008` | 正则删除 | 编号是文档定位信息，不是语言。留着的话每句开头都会是一个独一无二的“词”，模型会学到“句首后面跟一串数字”的假规律 |
| 拼音标注 `这{zhe4}` | 删除 `{...}` | 同一个词会变成 `这` 和 `这{zhe4}` 两个不同的 token，计数被拆散，加重数据稀疏 |
| 全角数字/字母 `１９９７年` | 转成半角 `1997年` | 统一写法，同理避免同一个词被拆成两个 |
| 段落 → 句子 | 遇到 `。！？` 切句，句首句尾加 `<s>` `</s>` | 段落太长，切成句子后 `<s>` 和 `</s>` 才有意义，生成时模型也知道在哪儿结束 |
| 编码 | 原文件是 GBK，按 GBK 读入 | 按 UTF-8 读会直接报错 |

一句话总结：**n-gram 只会数数，标签和编号也会被当成词来数**。不清理的话，概率会被和语言无关的符号拆散、污染。

## 2. 训练结果

| 设置 | 模型 | 训练用时 | 不同 n-gram 条目数 | 测试集困惑度 |
|---|---|---|---|---|
| 6 个月（731 万词） | 1-gram | 4.8 s | 13.7 万 | 1877 |
| | 2-gram | 15.5 s | 177 万 | 357 |
| | 3-gram | 33.9 s | 430 万 | **253** |
| 1 个月（112 万词） | 1-gram | 0.5 s | 5.3 万 | 1826 |
| | 2-gram | 1.8 s | 44 万 | 440 |
| | 3-gram | 4.5 s | 82 万 | 379 |
| | 4-gram | 9.0 s | 96 万 | 402 ↑ |

（训练集和测试集划分：每 20 句取 1 句做测试；困惑度用 Jelinek-Mercer 插值平滑计算，权重按阶数 1:2:4…… 递增。用时取决于电脑，仅供相对比较。）

**观察**
- **训练时间**：大致随数据量和阶数线性增长，每提高一阶都要多统计一层。条目数增长得更快，3-gram 的条目数是 1-gram 的约 30 倍，内存也主要花在这里。
- **阶数**：从 1 阶到 3 阶，困惑度大幅下降（1877 → 253），说明多看一两个词的上下文非常有用。
- **数据量和阶数要匹配**：只用 1 个月数据时，4-gram 的困惑度反而比 3-gram 高。大部分 4-gram 在测试集里没出现过，只能靠插值退回低阶，高阶分配到的权重白白浪费了。这正是课上讲的数据稀疏问题。数据越多，越能支撑更高的阶数。

## 3. 续写结果（节选，完整内容见运行结果文件）
开头先用正向最大匹配，按语料词表切成：`在 / 阳光 / 明媚 / 的 / 五月 / ， / 我们 / 学校 / 胜利 / 召开 / 了`

| 模型 | 参数 | 续写 |
|---|---|---|
| 2-gram | 贪心 | ……召开了，在北京5月，在北京5月，在北京5月……（死循环） |
| 3-gram | 贪心 | ……召开了“高增长、低通胀”的原则，在全国范围内的“中国威胁论”的原则，……（循环） |
| 3-gram | T=0.7, top-k=10 | ……召开了全省党政军民“同呼吸、共命运，与他们的工作。 |
| 3-gram | T=1.0 | ……召开了党的十五大精神和兼容各种思想文化的保护工作，努力降低工程成本，抢占市场竞争主体。 |
| 3-gram | T=1.5, top-k=50 | ……召开了本地区本部门经济的稳步发展的新高潮正在逐步发展壮大所建立的巧克力萨赫蛋糕尤以工艺考究…… |
| 4-gram（1个月） | 贪心 | ……召开了第十五次全国代表大会，高举邓小平理论伟大旗帜，把建设有中国特色社会主义的伟大事业。 |
| 4-gram（1个月） | T=1.0 | ……召开了全省消防工作会议。 |

**参数的影响**
- **贪心（温度 0）**：每步都选最高频的词，很快陷入循环。原因是 n-gram 只看前 n−1 个词，一旦回到同样的上下文，就会做出同样的选择。
- **温度**：温度越高，低频词越容易被选中。T=1.5 时句子越来越长、越来越乱，“巧克力蛋糕”这类离题内容开始出现。温度低时文本更保守。
- **top-k**：只在最常见的 k 个候选里抽样，可以过滤掉怪词，和适中的温度配合效果最好（T≈0.7~1.0，k≈10）。
- **阶数**：1-gram 完全不看上下文，生成的是乱序词堆。3-gram 局部通顺，但整体没有主题。4-gram 在 1 个月的小数据上经常**整段照搬原文**（“第十五次全国代表大会，高举邓小平理论伟大旗帜”），流畅来自背诵，不是生成能力。
- **语料风格**：无论开头写的是“学校”，续写都会滑向“会议、精神、工作”这类 1998 年党报的高频表达。模型只能复现训练语料的分布。

## 4. 实现要点（代码对应）
- `clean_line` / `load_corpus`：清理与切句
- `NGramModel.train`：同时统计 0 ~ n−1 阶上下文的计数，供平滑和回退使用
- `NGramModel.prob` / `perplexity`：插值平滑与困惑度
- `NGramModel.next_word`：生成时从最长的已见上下文开始回退，按 `计数^(1/T)` 加权抽样，可选 top-k
- `fmm_segment`：把续写开头切成和语料一致的词
