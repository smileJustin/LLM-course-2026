# 实验报告：基于人民日报语料的 n-gram 语言模型训练与文本续写

> 课程：2026 秋季 大语言模型与应用实践
> 作业：L1 第 125 页 编程作业“自己尝试进行训练”
> 代码：同目录下 `ngram.py`；原始输出：`运行结果_6个月.txt`、`运行结果_1个月_含4gram.txt`

## 一、实验目的
按作业要求完成四件事：
1. 清理人民日报切分语料中多余的 tag 和标签，并说明为什么必须清理；
2. 用清理后的语料进行 n-gram 建模训练；
3. 对比不同阶数、不同数据量下的训练时间，观察训练过程；
4. 设置不同参数，以“在阳光明媚的五月，我们学校胜利召开了……”为开头续写文本。

在此基础上，用实验结果回应课件第 119~123 页的几个核心问题：数据稀疏、平滑、阶数与数据量的关系，以及 n-gram 的结构性局限。

## 二、实验环境与数据
| 项目 | 说明 |

**关于“前面提到的工具”**：课件第 124 页介绍了 SRILM 和 KenLM 两个工业级 n-gram 工具包。本实验没有调用它们，而是用 Python 从零实现了“计数 → 平滑 → 评测 → 生成”的完整流程。这样做的目的是看清每一步在做什么，呼应作业里“产出的目标是理解，而不仅仅是能跑动的代码”的要求。两者的对应关系见第四节第 5 小节。

## 三、语料清理：清理了什么，为什么必须清理
原始语料一行的样子：
```
19980101-01-001-008 在 这{zhe4} 一 年 中 ， 中国 的 改革 开放 …… １９９７年 ……
```

| 清理项 | 做法 | 不清理会怎样 |
|---|---|---|
| 行首编号 `19980101-01-001-008`（日期-版面-文章-段落） | 正则删除 | 每行开头都多出一个独一无二的“词”，模型会学到“句首后接一串编号”这种与语言无关的规律，也会污染以 `<s>` 开头的条件分布 |
| 拼音标注 `这{zhe4}`、`上{shang5}` | 删除 `{…}` | 同一个词被拆成 `这` 和 `这{zhe4}` 两个 token。1 月份的语料里仅 `{zhe4}` 就出现 3392 次，计数被分散，加重数据稀疏 |
| 全角数字和字母 `１９９７年` | 转成半角 `1997年` | 同一个词有两种写法，同样会分散计数 |
| 段落 → 句子 | 遇到 `。！？` 切句，句首、句尾分别加 `<s>`、`</s>` | 一个段落可能有上百个词。切成句子后，`<s>`、`</s>` 才有明确含义，生成时模型也知道在哪里结束 |
| 编码 | 按 GBK 读入 | 按 UTF-8 读会直接报解码错误 |

**为什么必须清理**：n-gram 的训练本质上就是计数。它不懂哪些是语言、哪些是标注，所有以空格分开的符号都会被当成词来统计。标签不清理，会产生两个后果：一是**引入虚假的共现规律**，比如编号和句首词的搭配；二是**把同一个词的计数拆散**，让本来就严重的稀疏问题更严重。神经模型在一定程度上还能学会忽略噪声，n-gram 没有这种能力，所以“这次必须得清理”。

清理后的示例：`迈向 充满 希望 的 新 世纪 —— 一九九八年 新年 讲话 （ 附 图片 1 张 ）`

## 四、模型与实现

### 1. n 阶马尔可夫近似与最大似然估计
按链式法则，句子的概率是 $P(w_1,\dots,w_T)=\prod_t P(w_t\mid w_{\lt t})$。n-gram 只保留前 n−1 个词作为上下文：
$$P(w_t\mid w_{\lt t})\approx P(w_t\mid w_{t-n+1},\dots,w_{t-1})$$
训练就是“计数 + 归一化”得到最大似然估计（MLE）：
$$P_{ML}(w\mid h)=\frac{c(h,w)}{c(h)}$$
代码（`NGramModel.train`）中，`counts[k][上下文]` 是一个 `Counter`，记录长度为 k 的上下文后面各个词出现的次数。训练时 **0 ~ n−1 阶上下文会同时统计**，因为平滑和生成时的回退都要用到低阶分布。

### 2. 平滑：Jelinek–Mercer 线性插值
MLE 会给没见过的组合 0 概率，测试集只要出现一次没见过的 n-gram，整句概率就是 0，困惑度变成无穷大（课件第 119 页）。本实验采用课件第 120 页的 **JM 线性插值**：
$$P(w\mid h)=\sum_{k=0}^{n-1}\lambda_k\,P_{ML}(w\mid h_{\text{后}k\text{个词}})$$
- 权重按阶数 1:2:4:8… 递增并归一化，例如 3-gram 为 $\lambda=(1/7,\,2/7,\,4/7)$，越高阶权重越大；
- 1 阶分布用加一平滑，并为未登录词 `<unk>` 预留一份概率；
- 某阶上下文从没出现过时，这一阶的权重转交给 1 阶分布。

选择 JM 的原因是它最简单、最容易看清“把概率质量从高阶挪给低阶”这个思想。代价是权重 λ 是固定的，没有在验证集上调优，后面的 4-gram 实验会看到这个代价。

### 3. 评测指标：困惑度
$$\mathrm{PPL}=\exp\Big(-\frac{1}{N}\sum_{i=1}^{N}\ln P(w_i\mid h_i)\Big)$$
即测试集上平均每个 token 的负对数似然（交叉熵）取指数，可以理解为“模型在每个位置平均要在多少个候选词里犹豫”（课件第 110 页）。统计时包含句尾 `</s>`。

### 4. 文本生成
- **开头切词**：续写的开头是一句没有切分的原文，用正向最大匹配，按语料词表切成 `在 / 阳光 / 明媚 / 的 / 五月 / ， / 我们 / 学校 / 胜利 / 召开 / 了`，保证和训练语料的切分方式一致。
- **回退取候选**：从最长的 n−1 阶上下文开始查，查不到就逐级缩短上下文，直到找到见过的上下文为止。
- **解码参数**：
  - **贪心（温度 0）**：每步都取频次最高的词；
  - **温度 T**：按 $c^{1/T}$ 加权抽样。T<1 时分布更尖锐、更保守，T>1 时更平坦、更随机；
  - **top-k**：只在频次最高的 k 个候选里抽样，k=0 表示不限制。
- 生成到 `</s>` 或满 60 个词时停止，随机种子固定为 42，结果可以复现。

### 5. 与 SRILM / KenLM 的对照
| 环节 | 本实验 | SRILM / KenLM |
|---|---|---|
| 计数存储 | Python 字典 + `Counter` | 压缩 trie、probing hash 等专门的数据结构 |
| 平滑 | 固定权重的 JM 插值 | 默认用改进的 Kneser–Ney 平滑，折扣参数由数据估计 |
| 规模 | 731 万词上的 1~3 阶模型共占约 1.5GB 内存 | KenLM 可以在笔记本上装下几十 GB 的 5-gram |
| 作用 | 看清原理 | 工程上实际使用 |

如果用 KenLM 做同样的实验，只需要把清理后的语料按“每句一行、词之间空格分隔”写成文本文件，然后执行 `lmplz -o 3 < corpus.txt > model.arpa`。它会自动完成计数和改进 KN 平滑，效果通常会比本实验的固定权重 JM 更好。

## 五、实验设置
- **训练集和测试集**：按句子顺序，每 20 句取 1 句作为测试集，其余作为训练集。
- **实验 A（全量数据）**：1~6 月全部语料，训练 1、2、3-gram。
- **实验 B（小数据）**：只用 1 月语料（约 112 万词），训练 1、2、3、4-gram。
- **续写参数**：对每个模型分别使用 4 组解码参数：贪心、T=0.7 + top-k=10、T=1.0 不限 k、T=1.5 + top-k=50。

## 七、分析与讨论

### 1. 训练过程与训练时间
- n-gram 的“训练”只是遍历一遍语料做计数，没有迭代优化，所以不存在 loss 曲线，训练一次就结束。
- **训练时间与数据量大致成正比**：6 个月的数据量约为 1 个月的 6.5 倍，3-gram 的训练时间约为 7.5 倍（33.9 s 对 4.5 s）。
- **训练时间随阶数增加**：实现中训练 n 阶模型要同时统计 0 ~ n−1 阶上下文，每个词的计数操作是 n 次，所以 1→2→3 阶的用时大约按 1:3:7 增长。
- **真正的瓶颈是内存，不是时间**：3-gram 的不同条目数（430 万）是 1-gram 词表（13.7 万）的 30 多倍，1~3 阶模型一共占用约 1.5GB 内存，其中大部分是 3-gram。这直观地印证了课件第 121 页说的“参数/存储成本”，也说明了为什么工业界需要 KenLM 这类压缩数据结构，以及剪枝等技术。

### 2. 阶数的作用：困惑度大幅下降
在 6 个月语料上，困惑度从 1-gram 的 1877 降到 2-gram 的 357，再降到 3-gram 的 253。1-gram 完全不看上下文，相当于每个位置要在近两千个词里猜；看到前一个词以后，不确定性下降到原来的约五分之一。这正是 Shannon 预测实验揭示的规律：“上下文越长，不确定性越小”（课件第 113 页）。但从 2 阶到 3 阶的下降幅度（357→253）明显小于从 1 阶到 2 阶，边际收益在递减。

### 3. 数据量与阶数要匹配：小数据上的 4-gram
在 1 个月语料上，4-gram 的困惑度（401.8）反而比 3-gram（378.6）高。原因是：
- 4-gram 条目数达到 96 万，但大多数只出现一次，测试集中的 4 元组大部分在训练集里没见过；
- 本实验的 JM 权重是固定的，4 阶分到了 8/15 的权重。上下文没见过时，这部分权重会转给 1 阶分布；上下文见过但这个词没在它后面出现过时，这部分权重就几乎白白浪费了。

所以这个结果说明的是：**在数据不足、插值权重又不调优的情况下，提高阶数会适得其反**。它不说明 4-gram 一定比 3-gram 差。如果在验证集上调 λ，或者改用 Kneser–Ney 平滑，4-gram 的困惑度通常不会高于 3-gram。这正好回答了课件第 122 页的思考题“无限增大 n 能否解决长依赖”：n 越大，需要的数据呈指数增长，稀疏问题会先把模型压垮。“∞-gram”在有限数据上只能退化成查表背诵（见下一条）。

### 4. 解码参数的影响
- **贪心解码一定会陷入循环**。2-gram 反复生成“在北京5月”，3-gram 反复生成“……的原则，在全国范围内的……”。原因是 n-gram 只看前 n−1 个词：一旦回到同样的上下文，贪心就会做出完全相同的选择，形成死循环。这就是课件第 106 页说的，贪心/束搜索在开放式生成中容易“短视与枯燥”。
- **温度越高越随机**。T=1.5 时，3-gram 先生成了一串“发展、高潮、壮大”这类党报套话，然后跳到“巧克力萨赫蛋糕”，话题完全断裂。T=0.7 + top-k=10 的输出最稳妥，但往往很短。
- **抽样也可能马上结束**。1-gram 在 T=0.7、top-k=10 时什么都没生成，T=1.5、top-k=50 时只生成了“上，。”。因为句尾符号 `</s>` 本身就是高频 token，在最高频的前 10 或前 50 个候选里，第一步就可能被抽中。
- 实际使用中，较好的折中是 **T≈0.7~1.0 配合 top-k≈10**。课件推荐的 top-p（核采样）思路与 top-k 一样，都是截掉低概率的尾部。

### 5. 小数据高阶模型会“背书”
1 个月语料训练的 4-gram，贪心续写出“第十五次全国代表大会，高举邓小平理论伟大旗帜，把建设有中国特色社会主义的伟大事业”，T=1.0 时续写出“全省消防工作会议”。这些都是训练语料中原样出现过的片段。高阶上下文后面往往只跟过一个词，生成就退化成了复读原文。输出看起来流畅，但流畅来自记忆，而不是语言能力。这与课件第 121 页说的“n-gram 更像语料记忆器”一致。

### 6. 模型只能复现语料的分布
不管开头写的是“学校”，续写都会滑向“全省党政军民”“十五大精神”“工作会议”这类 1998 年党报的高频表达。原因是 n-gram 只学到了训练语料的条件分布，开头的“学校”只影响紧随其后的一两个词，影响不了后面的话题。长距离的主题一致性超出了固定窗口的能力范围，这正是后来需要神经语言模型和注意力机制的动因（课件第 121、123 页）。

## 八、局限与可改进之处
1. **插值权重没有调优**：λ 按 1:2:4:8 固定。改进方法是留出验证集，用网格搜索或 EM 算法估计 λ；或者直接换成改进的 Kneser–Ney 平滑（例如用 KenLM）。
2. **测试集不是完全独立的**：按句子每 20 句抽 1 句作为测试，同一篇文章的其他句子在训练集里，同一新闻事件的说法会在训练集和测试集中同时出现，困惑度会偏乐观。更严格的做法是按文章或按日期划分，比如用 1~5 月训练、6 月测试。
3. **内存占用高**：用 Python 字典同时存 1~3 阶模型（3-gram 有 430 万条）需要约 1.5GB，再提高阶数或增加语料会很快遇到内存瓶颈。可以借助 KenLM 的压缩结构，或者做计数剪枝，比如删除只出现一次的高阶 n-gram。
4. **训练时间受实现方式影响**：本实验的用时反映的是纯 Python 实现，不代表 n-gram 方法本身的速度。KenLM 等 C++ 工具会快一到两个数量级。
5. **生成只用了温度和 top-k**：可以再实现 top-p 核采样，以及禁止重复 n-gram 的约束，缓解贪心解码的循环问题。

## 九、对代码的理解
| 函数 | 作用 | 关键点 |
|---|---|---|
| `clean_line` / `load_corpus` | 清理与切句 | 三个正则或映射分别处理编号、拼音、全角字符；遇到 `。！？` 切句 |
| `NGramModel.train` | 计数 | 对每个位置同时更新 0~n−1 阶上下文的计数；句首补 n−1 个 `<s>` |
| `NGramModel.prob` | 插值概率 | 低阶用加一平滑兜底；上下文没见过时，该阶权重转给 1 阶 |
| `NGramModel.perplexity` | 困惑度 | 累加 −ln P 后求平均，再取指数 |
| `NGramModel.next_word` | 生成一个词 | 从最长上下文开始回退；按 计数^(1/T) 加权抽样，可选 top-k |
| `fmm_segment` | 切分开头句子 | 正向最大匹配，最大词长 6 |

## 十、复现方法
1. 把语料放在仓库根目录的 `1998-上半年-带音(1)/1998-上半年-带音/` 下。语料有版权，没有包含在仓库里。
2. 在 PyCharm 中运行 `ngram.py`，默认使用 6 个月语料，训练 1~3 阶模型。
3. 常用参数：
   - `--months 1 --max-n 4`：复现实验 B；
   - `--temperature 1.2 --top-k 20`：只用这一组参数续写；
   - `--data 路径`：指定语料所在位置。
